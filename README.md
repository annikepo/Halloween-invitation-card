# 🎃 Halloween Party Invitation Card

An interactive, animated Halloween party invitation card built with HTML, CSS, and JavaScript. 

Clicking the envelope triggers an opening animation sequence to reveal the invitation details inside!

---

## 🛠️ Built With

* **HTML5** – Page structure and image containers
* **CSS3** – Layout positioning, responsive sizing, and smooth opacity transitions
* **JavaScript (Vanilla)** – Click event listeners and state management for the envelope opening sequence
* **Canva / SVG** – Custom animated envelope artwork
